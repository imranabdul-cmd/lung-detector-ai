About This Project

This application is an educational tool designed to demonstrate the power of Artificial Intelligence in the field of medical imaging. It uses a deep learning model called a Convolutional Neural Network (CNN) to classify histopathological images of lung tissue.

The Technology

The AI model was built using Python with the TensorFlow and Keras libraries. In your final version, we can connect this UI to your uploaded dataset and training pipeline so the demo uses your own images, predictions, and metrics.

Our Goal

The primary objective is to showcase how AI can serve as a powerful assistive tool for medical professionals. By automating the initial analysis of images, such tools can help pathologists prioritize their work, reduce diagnostic time, and provide a consistent, data-driven second opinion.

Disclaimer

This is not a medical device. The predictions shown in this demo are for educational and interface demonstration purposes only and should never be used for actual medical diagnosis.
